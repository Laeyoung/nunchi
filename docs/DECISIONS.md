# Nunchi MVP 결정 기록

MVP를 만드는 동안 내린 결정과 그 근거를 적습니다. 새 결정은 표 맨 위에 추가합니다.

## 요약 (2026-11-04 기준)

- MVP 기능 완료: 촬영 → 후보 하이라이트 → 탭 → 설명 카드와 낭독 → "자세히"(웹 검색 근거와 출처). 데모 모드, 에러 처리, PWA 포함.
- iPhone 실기기 확인(P0-6)은 의뢰인에게 iPhone이 없어, Safari와 같은 엔진(WebKit)에서 iPhone 13 화면을 흉내 내 대신 확인했습니다(`scripts/webkit_check.py`). 실제 카메라와 iOS 음성 정책은 실기기에서만 확인할 수 있습니다.
- 앱 형태는 **모바일 웹앱(PWA)** 입니다. 설치 없이 휴대폰 브라우저에서 URL로 열고, 홈 화면에 추가할 수 있습니다.
- 탭에서 결과까지 약 8~9초(브라우저 실측). 데모 캐시는 19장 × ja·en 38건이고, "자세히" 결과도 함께 들어 있습니다.
- Meta 크레딧 추정 사용액은 **약 $3.8**이고 예산은 $50입니다. 잔액은 `python -m scripts.usage_report`로 확인합니다.

## 크레딧 추정

Meta API에는 잔액을 조회하는 방법이 없습니다. 그래서 응답의 `usage` 토큰 수에 공개 가격을 곱해 추정합니다.

| 항목 | 가격 | 1회 비용 |
| --- | --- | --- |
| muse-spark-1.3 | 입력 $1.25 / 출력 $4.25 (1M 토큰당) | 약 $0.0073 (입력 2,591 + 출력 947 토큰, 그중 추론 699) |
| sam-3.1 | 이미지 1,000장당 $2.50 | $0.0025 |
| web_search ("자세히" 버튼) | 1,000회당 $2.50 + 토큰 비용 | 약 $0.01 |

- 장부를 만들기 전 사용액은 **$3으로 추정**해 `PRIOR_SPEND_USD`에 넣었습니다(Spark 약 175회, SAM 약 35회). 초기에 추론 `low`로 돌린 호출을 감안해 넉넉하게 잡은 값입니다.
- 데모 캐시 38건을 다시 채우는 데 약 $0.4, 회귀 테스트 1회(40건)에 약 $0.4가 듭니다.
- 가격 출처: [Pricing and rate limits](https://dev.meta.ai/docs/pricing-rate-limits) (2026-11-03 확인)
